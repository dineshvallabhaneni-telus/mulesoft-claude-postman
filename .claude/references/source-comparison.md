# Source Comparison Reference

## Sources

Git source:

workspace/mulesoft-repository

Anypoint artifact:

workspace/anypoint-artifact/extracted

## Required Comparison

Compare all relevant files.

At minimum:

- XML
- properties
- YAML
- YML
- JSON
- Mule configuration
- application configuration
- resources
- scripts
- templates

## Differences

Identify:

- missing files
- additional files
- modified files
- XML differences
- properties differences
- configuration differences
- other relevant content differences

## Equality

Actual file contents must be compared.

File names alone are insufficient.

File structure alone is insufficient.

## Result

MATCH requires no relevant differences.

MISMATCH occurs when any relevant difference exists.

MISMATCH blocks Postman execution.
